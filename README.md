# Echo

Landing page for Echo, voice agents for Indian enterprise.

Live: https://theruka7.github.io/qoyal/

A single static page (`index.html`) with no build step. To wire it up, edit `ECHO_CONFIG` at the top of the script:

- `PILOT_ENDPOINT` or `PILOT_EMAIL`: where the pilot and demo forms send.
- `AUDIO_DIR` and `AUDIO_FILES`: real call recordings, if you add any.

The agent try-outs run in the browser (script, rules, browser voice and mic). They are previews, not the live agent.
