## The product in five steps

Echo turns a phone call your team makes every day into an agent that makes it for you. Every agent follows the same path from idea to results.

<CardGroup cols="5">
<Card title="Create an agent" href="agents" eyebrow="1 · Build">Write what it should say and what it must find out.</Card>
<Card title="Talk to it" href="testing" eyebrow="2 · Test">From your browser or on a real phone.</Card>
<Card title="Run a campaign" href="campaigns" eyebrow="3 · Launch">Upload a sheet. Echo calls every row.</Card>
<Card title="Watch results" href="monitoring" eyebrow="4 · Monitor">Status, outcomes and recordings, live.</Card>
<Card title="Use the outcomes" href="analysis" eyebrow="5 · Act">Export, analyse, and write back.</Card>
</CardGroup>

## Two ways to work

<Columns>
<Column>
### Business teams

Create an agent from a template or a copy, fill in a sheet, and run it. No code. The **Platform guide** in this sidebar is written for you.

</Column>

### Developers

Run the same agents from your own systems: create campaigns, send contacts and read outcomes over an API, or receive them on a webhook. The API is in developer preview.
