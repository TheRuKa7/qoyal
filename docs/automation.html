Scale

Automation and reports

For teams running calls every day: start calls from your systems and schedules, clean up messy lists, route rows to the right agent, and send reports automatically.

Updated 25 Sep 20262 min readView as Markdown

These features are available on enterprise workspaces. Your account team switches them on and sets them up with you.

Run agents from sheets Enterprise#

A single Run view lists every live agent with how many calls it has run and its success rate. For each one: Get sheet, fill it in, Upload and run. Bulk uploads auto-match columns by name, show which required fields are still unmapped, and return a result sheet listing any rows that failed and why.

Event triggers Enterprise#

An agent can start a call on its own when something happens in your systems, for example when a purchase order is created or updated. You choose:

  • which events start a call;
  • where in the event to find the contact’s phone and details;
  • how many times to retry and how long to wait between attempts.

Schedules Enterprise#

Run an agent on a schedule: on chosen days of the week, a day of the month, every few hours, or once on a date, at the time you pick.

Data clean-up and enrichment Enterprise#

  • Enrichments are lookups that fill blanks in an upload, such as a missing contact number or name.
  • Transformations turn one messy upload into clean, call-ready sheets before any call is placed.

Routing rows to agents Enterprise#

Split one upload across several agents with lanes. Each lane keeps the rows that match its rules, sorts them, groups rows for the same person into one call, and sends them to an agent. Paste a header row to preview how well each lane’s agent inputs would be matched.

Scheduled reports Enterprise#

Build a report for an agent: pick its columns, filters and date format. Then schedule it by email with a subject, message, recipients and a data window, such as the last seven days on every send. Keep every send in one email thread if you prefer.

Ask your data Enterprise#

Dashboards show calls, answers and commitments over time, and you can ask questions of your call data in plain English to get a table or chart back.

Multi-item calls Preview#

When one person has several open items, such as many PO lines, Echo can cover them in one call instead of many. The design:

  • group items by person and sort them into priority bands;
  • cap how many items one call covers, check in after a set number, and stop at a hard limit;
  • close an item only when its numbers add up, and re-ask inside the call when they do not;
  • end every item with exactly one outcome from a fixed list.

Talk to your account team if this fits your calls.
