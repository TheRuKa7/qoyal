API quickstart.

The same agents your business team builds in the dashboard, driven from your own systems.

Overview

Everything you can do in the Echo dashboard, you can do over the API. The model is small:

  • Agents hold the script, language and the fields to capture. Create them in the dashboard, then refer to them by id.
  • Calls are single conversations with one person.
  • Campaigns run an agent over a list of contacts, inside your calling window, with retries.
  • Results are the structured outcome of each call, with the recording attached.
This is a developer preview. Endpoints and fields may change before general availability. API keys are issued to pilot customers. Request access.

Authentication

Send your API key as a bearer token on every request. Keep keys on your server, never in a browser or app.

Authorization: Bearer $ECHO_API_KEY
Content-Type: application/json

Agents

Build and test agents in the dashboard, in simple mode. Each agent has an id you use in API calls, for example dispatch-followup. The agent defines what it asks, what it reads back, and which outcome fields it returns.

Place a call

POST/v1/calls

Starts one call with an agent. Pass anything the agent needs to know in context.

curl -X POST "$ECHO_API/v1/calls" \
  -H "Authorization: Bearer $ECHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "+919876543210",
    "agent": "dispatch-followup",
    "context": { "po_number": "4471", "line": 3, "qty": 14 }
  }'
{ "call_id": "call_8f2k", "status": "queued" }

Campaigns

POST/v1/campaigns

{ "agent": "dispatch-followup", "name": "Open POs, week 39" }

Calling windows, retries and call backs follow the settings on the campaign. Calls only start inside the hours you set.

Add contacts

POST/v1/campaigns/{id}/contacts

Upload a sheet (CSV or XLSX) or send JSON rows. Columns are mapped to the fields the agent expects. Rows for the same phone number become one call.

curl -X POST "$ECHO_API/v1/campaigns/$CAMPAIGN_ID/contacts" \
  -H "Authorization: Bearer $ECHO_API_KEY" \
  -F "file=@open_pos.xlsx"

Webhooks

Subscribe a URL and receive each outcome as it lands, instead of polling. Every webhook is signed. Verify the signature before you trust the payload, and respond with a 2xx status within a few seconds.

POST https://your-app.example.com/echo/outcomes
X-Echo-Signature: t=1727251200,v1=…

{ "event": "call.completed", "call_id": "call_8f2k", "outcome": "CONFIRMED", "fields": { … } }

Outcome fields

FieldTypeMeaning
outcomestringStatus such as CONFIRMED, PARTIAL, NEW_DATE, CALL_BACK, NOT_REACHED.
read_back_confirmedbooleanTrue when the caller confirmed the read-back with a clear yes.
fieldsobjectThe values your agent captures, such as dates, amounts and reasons.
next_stepobjectA call back time or follow-up, when there is one.
recording_urlstringLink to the call recording.
