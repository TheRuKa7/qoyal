Get started

Echo documentation

Build a voice agent in Echo, test it, run it on a list of suppliers or customers, and use every outcome. No code needed.

Updated 29 Sep 20261 min read

Echo turns a call your team makes every day into an agent that makes it for you, and writes back what each call found out. This guide covers everything in the Echo console.

From idea to results#

  1. Create an agent

    Write what it should say and what it must find out. Create an agent →

  2. Test it

    Talk to it from your browser or on a real phone, and watch the values it captures. Call console →

  3. Run a campaign

    Upload a sheet and confirm the columns. Echo calls every row. Create and run a campaign →

  4. Use the outcomes

    Read every response, recording and transcript, and download them for your systems. Results and exports →
