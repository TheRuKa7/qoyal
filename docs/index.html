Moglix Echo documentation

Everything you need to build a voice agent, test it, run it on a list, and use what it hears.

The product in five steps

Echo turns a phone call your team makes every day into an agent that makes it for you. Every agent follows the same path from idea to results.

1 · BuildCreate an agentWrite what it should say and what it must find out. 2 · TestTalk to itFrom your browser or on a real phone. 3 · LaunchRun a campaignUpload a sheet. Echo calls every row. 4 · MonitorWatch resultsStatus, outcomes and recordings, live. 5 · ActUse the outcomesExport, analyse, and write back.

Two ways to work

Business teams

Create an agent from a template or a copy, fill in a sheet, and run it. No code. Everything on this site except the API page is for you.

Start with the quickstart →

Developers

Run the same agents from your own systems: create campaigns, send contacts and read outcomes over an API, or receive them on a webhook.
