Get started

Echo documentation

How to build a voice agent in Echo, test it, run it on a list of suppliers or customers, and use the outcomes. No code needed.

Updated 29 Sep 20261 min readView as Markdown

The product in five steps#

Echo turns a phone call your team makes every day into an agent that makes it for you. Every agent follows the same path from idea to results.

1 · BuildCreate an agent

Write what it should say and what it must find out.

 2 · TestTalk to it

From your browser or on a real phone.

 3 · LaunchRun a campaign

Upload a sheet. Echo calls every row.

 4 · MonitorWatch results

Status, outcomes and recordings, live.

 5 · ActUse the outcomes

Export, analyse, and write back.

Two ways to work#

Business teams#

Create an agent from a template or a copy, fill in a sheet, and run it. No code. The Platform guide in this sidebar is written for you.

Start with the quickstart →

Developers#

Run the same agents from your own systems: create campaigns, send contacts and read outcomes over an API, or receive them on a webhook. The API is in developer preview.

Open the developer docs →
