Get started

Echo for developers

Build and run Echo voice agents from your terminal, your AI coding tools and your own systems, with the Reverb CLI, the Relay MCP server, agent skills and the REST API.

Updated 29 Sep 20261 min read

Everything in this tab is Coming soon. The pages show how each tool will work, so you can plan an integration now. Your business team can already build, test and run agents in the Echo console; see the Platform guide.

The tools#

Command lineReverb CLI

Log in, scaffold agents, test them and run campaigns from your terminal. The main way to build with Echo.

 AI toolsRelay MCP server

Give Claude Code, Cursor and other MCP clients the same actions as the CLI.

 AI toolsAgent skills

Teach AI coding tools to write correct Echo prompts, variables and webhook handlers.

 HTTPREST API

Calls, campaigns, results and webhooks, for any language.

Which one to use#

You want to Use
Build and test agents day to day Reverb CLI
Let an AI assistant draft, test and run agents Relay MCP server with agent skills
Place a call when something happens in your ERP REST API and webhooks
Pull results, recordings and transcripts into your storage Exports

The object model#

TEXT
Agent ── has ──► inputs, outputs, prompt, voice, calling line
  │
  ├─► Call        one conversation   →  outputs, transcript, recording, analysis
  │
  └─► Campaign    one list           →  contacts  →  calls  →  results

Every tool works on these same objects, so an agent built in the console, the CLI or the API is the same agent. Core objects lists every field.
