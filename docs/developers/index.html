Get started

Echo for developers

Place calls, run campaigns and read outcomes from your own systems. The same agents your business team builds, driven by code.

PreviewThe API is in developer preview. Endpoints and fields may change before general availability, and keys are issued to pilot customers. Request access.

What you can build

  │
  └─► Campaign    one list           →  Contacts  →  Calls  →  Results

Read Core objects for every field.

Conventions

  • Base URL: shared with your API key. All paths start with /v1.
  • Auth: Authorization: Bearer <key> on every request. See Authentication.
  • Format: JSON in and out, UTF-8. Timestamps are ISO 8601 in UTC. Phone numbers are E.164.
  • Lists are paginated with limit and cursor; the response carries next_cursor, which is null on the last page.
  • Errors return a JSON error object with a stable code. See Errors.
