API reference

Agents

An agent owns the prompt, voice, calling line and the variables for one kind of call. Most teams build agents in the dashboard and use these endpoints to read them, clone them, or keep prompts in version control.

GET/v1/agents

List agents

Returns the agents in your workspace, newest first.

Query parameters

limitinteger

1 to 100. Default 25.

cursorstring

The next_cursor from the previous page.

Request
curl "$ECHO_API/v1/agents?limit=25" \
  -H "Authorization: Bearer $ECHO_API_KEY"
import os, requests

API = os.environ["ECHO_API"]
HEADERS = {"Authorization": f"Bearer {os.environ['ECHO_API_KEY']}"}

res = requests.get(
    f"{API}/v1/agents",
    headers=HEADERS,
    params={"limit": "25"},
)
res.raise_for_status()
print(res.json())
const API = process.env.ECHO_API;
const KEY = process.env.ECHO_API_KEY;

const res = await fetch(`${API}/v1/agents?limit=25`, {
  headers: { Authorization: `Bearer ${KEY}` },
}});
if (!res.ok) throw new Error(`Echo API ${res.status}`);
console.log(await res.json());

POST/v1/agents

Create an agent

Creates an agent. Start blank or copy an existing agent’s prompt, inputs and outputs.

Body

namestringrequired

Shown to your team. The id is derived from it.

descriptionstring

What the agent is for.

copy_fromstring

Id of an agent to copy.

calling_linestring

Line the agent dials from. Campaigns cannot dial until this is set.

Request
curl -X POST "$ECHO_API/v1/agents" \
  -H "Authorization: Bearer $ECHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "COD confirmation",
    "description": "Confirms cash on delivery orders before dispatch",
    "copy_from": "wismo",
    "calling_line": "cx-outbound"
  }'
import os, requests

API = os.environ["ECHO_API"]
HEADERS = {"Authorization": f"Bearer {os.environ['ECHO_API_KEY']}"}

res = requests.post(
    f"{API}/v1/agents",
    headers=HEADERS,
    json={
  "name": "COD confirmation",
  "description": "Confirms cash on delivery orders before dispatch",
  "copy_from": "wismo",
  "calling_line": "cx-outbound"
},
)
res.raise_for_status()
print(res.json())
const API = process.env.ECHO_API;

const res = await fetch(`${API}/v1/agents`, {

PATCH/v1/agents/{agent_id}

Update an agent

Changes settings. Each change applies to the next call, with no restart.

Path parameters

agent_idstringrequired

The agent id.

Body

namestring

descriptionstring

voicestring

A voice from options. null uses the default.

calling_linestring

primary_idstring

Key of the input that identifies each contact.

Request
curl -X PATCH "$ECHO_API/v1/agents/dispatch-followup" \
  -H "Authorization: Bearer $ECHO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "voice": "meera",
    "primary_id": "po_number"
  }'
import os, requests

API = os.environ["ECHO_API"]
HEADERS = {"Authorization": f"Bearer {os.environ['ECHO_API_KEY']}"}

res = requests.patch(
    f"{API}/v1/agents/dispatch-followup",
    headers=HEADERS,
    json={
  "voice": "meera",
  "primary_id": "po_number"
},
)
res.raise_for_status()
print(res.json())
const API = process.env.ECHO_API;
const KEY = process.env.ECHO_API_KEY;

const res = await fetch(`${API}/v1/agents/dispatch-followup`, {
  method: "PATCH",
  headers: { Authorization: `Bearer ${KEY}`, "Content-Type": "application/json" },
  body: JSON.stringify({
    "voice": "meera",
    "primary_id": "po_number"
  }),
}});
if (!res.ok) throw new Error(`Echo API ${res.status}`);

PUT/v1/agents/{agent_id}/prompt

Replace the prompt

Replaces all sections. The new prompt is live on the next call for every campaign that uses the agent.

Path parameters

agent_idstringrequired

Body

sectionsarrayrequired

Ordered list of {title, body, kind, enabled}. kind is text, inputs or outputs. An empty body on a generated section keeps it following the variables.

NoteIf a section uses a {{token}} that is not an input, it is listed in missing_tokens. Fix these before calling.
Request
curl -X PUT "$ECHO_API/v1/agents/dispatch-followup/prompt" \
  -H "Authorization: Bearer $ECHO_API_KEY" \
  -H "Content-Type: application/json" \

    "sections": [
      {
        "title": "Role and goal",

PUT/v1/agents/{agent_id}/inputs

Replace input variables

Sets what the agent knows before each call. Each input is a column in the upload template and a {{token}} in the prompt.

Path parameters

Body

List of {key, type, transform, sample, share_on_call}. transform: "spell_digits" reads a value digit by digit. share_on_call: false gives the value to the agent but it is never spoken.
