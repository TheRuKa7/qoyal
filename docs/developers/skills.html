Agent skills

Echo skills teach AI coding tools how to write Echo agents, prompt sections, variables and webhook handlers that work the first time.

Updated 29 Sep 20261 min read

Coming soon

The skills pack is not released yet. Ask your account team for early access.

A skill is a short, focused guide an AI coding tool loads when a task needs it. The Echo pack follows the open Agent Skills format, so it works in Claude Code, Cursor and other tools that support it.

What is in the pack#

Skill Helps the assistant to
Write an agent Lay out prompt sections: role and goal, flow, read-back rules, common moments, language, closing.
Declare variables Pick input and output names, types and descriptions, and keep the automatic sections in step.
Read-back rules Confirm dates, amounts and codes before anything is saved.
Handle webhooks Verify signatures and write each outcome to your ERP or CRM once.
Test before launch Plan test calls in the console or with Reverb and check every output.

Use it with Relay#

With the Relay MCP server connected, the assistant can apply what the skills describe: draft a prompt, run a test, and show you the captured outputs before you save.
