Analytics

The same funnel you see on the dashboard, for your own reports.

PreviewPart of the developer preview. Fields may change before general availability.
GET/v1/metrics

Retrieve the funnel

Counts for a period, from uploaded rows to confirmed outcomes.

Query parameters

daysinteger

Look-back window. Default 30.

agentstring

campaign_idstring

Request
curl "$ECHO_API/v1/metrics?days=30" \
  -H "Authorization: Bearer $ECHO_API_KEY"
import os, requests

API = os.environ["ECHO_API"]
HEADERS = {"Authorization": f"Bearer {os.environ['ECHO_API_KEY']}"}

res = requests.get(
    f"{API}/v1/metrics",
    headers=HEADERS,
    params={"days": "30"},
)
res.raise_for_status()
print(res.json())
const API = process.env.ECHO_API;
const KEY = process.env.ECHO_API_KEY;

const res = await fetch(`${API}/v1/metrics?days=30`, {
  headers: { Authorization: `Bearer ${KEY}` },
}});
if (!res.ok) throw new Error(`Echo API ${res.status}`);
console.log(await res.json());
